# 택시 미터기 시뮬레이터 (Taxi Meter Sim)

GPS로 잰 거리와 시간으로 택시 요금을 계산해 보는 **참고용 시뮬레이터**입니다. 화면은 실제 택시 미터기처럼 7세그먼트 LCD로 만들었고, 가운데 말이 **속도에 따라 점점 빨리 달리다가 차가 서면 멈춥니다**. 웹앱(PWA)이며 안드로이드 APK로도 만들 수 있습니다. 데이터는 기기 안(localStorage)에만 저장됩니다.

> **실제 택시 요금·법정 택시미터기를 대체하지 않습니다.** 택시 미터기는 법적으로 검정을 받는 계량기로 알고 있으며(법령은 직접 확인하지 못함 — **확인 필요**), 이 앱의 금액은 참고용입니다.

## 사용법

화면 아래 7개 키는 실제 미터기 배열을 따라 했습니다.

| 키 | 동작 |
|---|---|
| 빈차 `VACANT` | 대기 상태 표시. 운행 중에 누르면 **운행 취소**(기록 안 함) |
| 주행 `HIRED` | 미터 시작 (GPS 거리 측정, 위치 권한 필요) |
| 심야 `NIGHT` | 지금 적용 중인 심야 할증 안내 (시각에 따라 자동 적용) |
| 통행 `TOLL` / 호출 `CALL` | 통행료·호출료 입력 (원 단위 그대로 더함, 100원 반올림 안 함) |
| 시계외 `SUR` | 시계외 할증 켜기/끄기 (운행 중에도 가능) |
| 지불 `STOP` | 운행 종료 → 영수증, 기록 저장 |

그 밖에: **▶ 데모 주행**(GPS 없이 가상의 도시 주행. ×1/×5/×20 배속, 시작 시각 22:30/23:30/02:30 선택으로 심야 할증 확인), **⚙ 요금 설정**, **🧾 운행 기록**.

왼쪽 램프(VACANT/HIRED/NIGHT/STOP)와 아래 표시등(BASE/DIST/TIME/OUT)이 지금 상태를 보여 줍니다. STOP 램프는 차가 서 있을 때 켜집니다.

## 요금 계산 모델

(`meter.js`, 모두 설정에서 바꿀 수 있음)

1. 출발하면 **기본요금**이 먼저 표시됩니다. 기본거리를 다 쓸 때까지는 대기 시간도 요금이 오르지 않습니다.
2. 이후 **거리 단위**(m)마다 **단위 요금**이 더해집니다.
3. 속도가 `거리 단위 ÷ 시간 단위`(기본 약 15.7 km/h) **미만**이면 거리 대신 **시간**으로 셉니다 (시간·거리 병산). 정차·정체 때 시간 요금이 쌓입니다.
4. **심야 할증**은 요금이 발생한 시각의 할증률을 곱합니다(자정을 넘는 구간 지원).
5. **시계외 할증**은 전체 요금에 대한 비율로, 심야 할증과 합산됩니다.
6. 표시 요금은 **반올림 단위**(기본 100원)로 반올림하고, 통행료·호출료는 그대로 더합니다.

## GPS와 말의 움직임

- 위치 정확도가 50 m보다 나쁜 값, 순간이동(초속 70 m 초과)은 버립니다. 속도 값(도플러)이 있으면 그걸 우선해서 정차 중 GPS 흔들림이 거리로 잡히지 않게 합니다 (`FixTracker`).
- 시간은 GPS와 별개로 1초마다 흐르므로, 위치가 안 들어와도 정차 시간 요금은 쌓입니다. 대신 **GPS가 끊긴 동안 거리는 측정되지 않습니다.**
- 말(`horse.js`): 속도 → 보폭 주기(`strideHz`: 0.5 km/h 미만 0, 이후 속도에 비례해 증가, 최대 5 Hz)와 다리 흔들림 크기(`ampFor`)를 정하고, 목표값을 향해 부드럽게 가속·감속합니다. 멈추면 서 있는 자세로 돌아가고 애니메이션 루프도 꺼집니다.
- **화면을 켜 둬야 합니다.** 웹에서는 화면 켜짐 유지(Wake Lock)를 요청하고, APK는 앱이 켜져 있는 동안 화면이 꺼지지 않게 합니다. 백그라운드 위치 추적(네이티브 서비스)은 포함하지 않았습니다.
- 운행 중에 페이지를 새로고침하거나 닫으면 그 운행은 사라집니다.

## 실행·테스트

```
python3 -m http.server 8080          # http://localhost:8080
node tests/run.js                    # 요금 엔진·GPS 필터·말·LCD 단위 테스트
BASE_URL=http://localhost:8080/index.html NODE_PATH=$(npm root -g) node tests/e2e.cjs [스크린샷폴더]   # Playwright, GPS 에뮬레이션
```

GPS(`navigator.geolocation`)는 **HTTPS 또는 localhost**에서만 동작합니다.

## 배포 (GitHub Pages)와 Android APK

- `.github/workflows/pages.yml`: 테스트 후 정적 사이트를 Pages에 배포합니다(기본 브랜치에서만). 저장소 **Settings → Pages → Source: GitHub Actions**로 한 번 바꿔야 합니다.
- `.github/workflows/android.yml`: Capacitor 8.5.3으로 감싼 APK를 만들어 Releases의 `android-latest`에 올립니다. 위치 권한, 세로 고정, 화면 켜짐 유지, 아이콘은 `tools/android-patch.sh`와 `android-res/`에 있습니다.
- APK는 공개 저장소에 올라 있는 **고정 테스트 키**(`tools/taxi-debug.keystore`)로 서명합니다. 개인 테스트용이며 플레이스토어에는 쓸 수 없습니다. 고정 키 덕분에 새 빌드가 이전 빌드 위에 설치되어 기록이 유지됩니다.
- iPhone용(IPA)은 Mac/Xcode와 Apple 개발자 계정이 필요해서 지원하지 않습니다 — 웹앱을 쓰세요.

## 구조

| 파일 | 역할 |
|---|---|
| `meter.js` | 요금 엔진, 설정 검증, GPS fix 필터(`FixTracker`), 포맷 — 순수 함수 |
| `sim.js` | 데모 주행 속도 곡선 |
| `horse.js` | 말의 관절 각도(`pose`), 속도→보폭(`strideHz`), SVG 구동 |
| `lcd.js` | 7세그먼트 LCD (꺼진 세그먼트가 희미하게 보임) |
| `app.js` | 화면·GPS·키·대화상자·기록 |
| `sw.js`, `manifest.webmanifest` | 설치·오프라인 |
